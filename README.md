# Portafolio personal · Jose Abril

Portafolio web de **Jose Abril (ESJ0)**, estudiante de Ciencias de la Computación y desarrollador full-stack. El sitio presenta mi perfil, aptitudes, tecnologías y proyectos de desarrollo web, móvil y gráficos por computadora.

🌐 **Sitio:** [https://esj0.github.io](https://esj0.github.io)

## Características

- Presentación animada con efecto de escritura.
- Resumen del stack tecnológico por capas.
- Sección personal con aptitudes principales.
- Habilidades organizadas en carpetas desplegables con sus respectivos iconos.
- Proyectos disponibles como carrusel o cuadrícula.
- Diseño adaptable para escritorio, tablet y móvil.
- Contacto directo mediante Gmail, GitHub y LinkedIn.
- Navegación y animaciones compatibles con preferencias de movimiento reducido.

## Tecnologías

- HTML5
- CSS3
- JavaScript
- Google Fonts
- Devicon
- GitHub Pages

No requiere instalar paquetes ni ejecutar un proceso de compilación.
